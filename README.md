# Desq Docs

A clean, browser-based document editor built with React, TipTap, Vite, and Tailwind CSS.

## Features

- Multiple local documents with automatic browser storage
- Light and dark mode
- Bold, italic, underline, strikethrough, headings, quotes, code, lists, and checklists
- Font family, font size, text color, highlight color, links, and alignment controls
- Word and character counts
- HTML/TXT export and print support
- GitHub Pages deployment workflow

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repo includes a GitHub Pages workflow that builds and deploys from `main`.

You can also publish locally with:

```bash
npm run deploy
```
